# PLAN: Улучшение 3 — Научная честность механизмов: починить B1-B5, B7 или честно задокументировать

- **Date:** 2026-09-05 · **Status:** draft (вне green-suite) · **Приоритет:** P0 (научная корректность)
- **Оценка пользы:** сейчас 5 из 12 механизмов при λ>0 либо ничего не делают, либо активно вредят;
  абляции и выводы бумаги на них недействительны. Трудоёмкость: высокая (3-5 дней), риск средний
  (меняется поведение λ>0 — но дефолты λ=0, так что дефолтные прогоны идентичны).

## Проблема (доказательства)
- **B1 STA no-op**: sta.py:276-293 — лосс из буферов, обновляемых в @torch.no_grad (:181-231);
  градиентов нет; lambda_sta фиктивна.
- **B2 PUC no-op**: puc.py:196-197 — eigenvalues из EMA-буфера; дифференцируемый путь
  use_differentiable_entropy (puc.py:188-195) никем не включается (jepa.py:529-535 не передаёт);
  гейт if entropy_deficit > 0 на Python-float (puc.py:235).
- **B3 CMC тренирует не то**: train.py:1073-1080 — второй проход получает masked_input_ids
  (первичная маска m₁) со второй маской m₂ → инвариантность к паттерну маски не воспроизводится;
  комментарий train.py:1066-1067 о detach ложен (градиент течёт в encoder+predictor).
- **B4 WSD↔JAWP конфликт**: wsd.py:253 тянет Q к top-k PCA дисперсии таргета; JAWP (jawp.py:45-57)
  ищет bottom-k остатка; jawp.py:100-102 явно удалил variance-штраф как конфликтующий.
- **B5 RDC штрафует дисперсию данных**: rdc.py:154-162 — drift = z_current − EMA(mean прошлого
  батча) = разность разных документов; при λ_rdc>0 провоцирует коллапс, противоречит докстрингу.
- **B7 WSR sam тихий ноль**: wsr.py:402-428 требует loss_fn, jepa.py:1031 не передаёт → loss ≡ 0.
- Контекст: proofs/IMPLEMENTATION_STATUS.md — Divergent 5-8 у всех 12 механизмов; README
  («CGN and STA reconciled») матрице противоречит; ≥17 ложных «аудит»-комментариев в коде.

## Решение (по приоритету)
1. **CMC (B3)**: генерировать m₂ ДО первого forward; второму проходу передавать вход, маскированный
   именно m₂ (из collator), и m₂ в mask_positions. Регресс-тест: перекрытие m₁∩m₂ предсказаний
   падает, если второй проход получает m₁-вход.
2. **PUC (B2)**: пробросить use_differentiable_entropy из TextSpanJEPAConfig; гейт дефицита —
   дифференцируемый (torch) или вынести из графа явно как diagnostics-gate с документацией.
3. **STA (B1)**: вариант A — дифференцируемый текущий спектр (eigvalsh batch-cov с autograd,
   ref — из буфера, detach); вариант B (честнее) — объявить diagnostic-only, убрать из total_loss,
   λ_sta удалить из конфига с DeprecationWarning.
4. **WSD (B4)**: переформулировать target как top-k предсказуемых направлений (ковариация остатков
   предсказаний) ИЛИ удалить механизм; в обоих случаях — примечание в proofs/wsd.md.
5. **RDC (B5)**: z_previous по тому же входу (требовать явный z_previous как в rdc_compensate) или
   штраф дрейфа последовательных шагов параметров, не батчей разных документов.
6. **WSR (B7)**: передать loss_fn-замыкание из train loop или удалить режим 'sam' из валидации.
7. Вычистить ложные «аудит»-комментарии (R11-R18) в AUDIT.md с фиксацией фактического статуса.
